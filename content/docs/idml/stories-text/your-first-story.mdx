**A story is text plus the runs that format it. Three small steps show the whole model: one line, a second paragraph, a change of formatting.**

**In short:** The smallest story is a `Story` holding one `ParagraphStyleRange`, holding
one `CharacterStyleRange`, holding one `Content` element. To add a paragraph you do not
add an element: you end the first paragraph with a `<Br/>` mark and keep writing. To
change formatting you split the run where the formatting changes. Each step below is a
complete package, checked by opening it in InDesign and rendered live on this page.

## Step 1: one line of text

Here is the complete story from the smallest valid package. Read it from the inside out:
`Content` holds the characters; the `CharacterStyleRange` around it says how they are
formatted (here, the default character style); the `ParagraphStyleRange` says how the
paragraph is formatted (the default paragraph style); and the `Story` carries the `Self`
id that a text frame points at to display the text.

</ExampleEmbed>

## Step 2: a second paragraph

To start a second paragraph, end the first one with `<Br/>`, the paragraph mark, and add
the next text. Both paragraphs share the same formatting, so they stay in the same runs.
The last paragraph of a story never ends with a mark.

<ExampleEmbed example="two-paragraphs">
  One run, two paragraphs: the `<Br/>` on line 7 is where the first one ends.
</ExampleEmbed>

## Step 3: a change of formatting

Formatting changes split runs. Here both runs apply the same character style, `Emphasis`,
and the second overrides its size on the range itself, so the text is split into two
`CharacterStyleRange` elements at the point where the size changes. A change of
*paragraph* formatting would split the `ParagraphStyleRange` the same way, at a
paragraph's end.

<ExampleEmbed example="local-override">
  The same style twice; the second run overrides `PointSize`, so the text splits into
  two character runs.
</ExampleEmbed>

That is the whole model: text, with paragraph marks in it, under two layers of
non-overlapping runs. [Story structure](/docs/idml/stories-text/story-structure) is the
full reference, and [the paragraph model](/docs/idml/stories-text/the-paragraph-model)
explains why IDML works this way.

## Frequently asked questions

**What is the minimum a story needs to show a line of text?**
A `Story` wrapping one `ParagraphStyleRange`, wrapping one `CharacterStyleRange`,
wrapping one `Content` element with the text, as in step 1.

**How do I add a second paragraph?**
End the first one with `<Br/>` and continue the text. You only need a new
`ParagraphStyleRange` if the new paragraph is formatted differently.

**When does a new `CharacterStyleRange` start?**
Wherever any character attribute changes: the style, or a local override such as the
size, font or colour.
