**`Justification` sets how a paragraph's lines sit in the column; the spacing and hyphenation attributes set how much the composer may stretch, squeeze and split words to get there.**

**In short:** `Justification` takes three ragged values (`LeftAlign`, `CenterAlign`,
`RightAlign`), four justified values that differ in how the last line is set
(`LeftJustified`, `CenterJustified`, `RightJustified`, `FullyJustified`) and two
binding-relative values. In justified text, the composer stretches word spaces within the
paragraph's `MinimumWordSpacing`…`MaximumWordSpacing` range and, if allowed, letter spacing and
glyph scaling too. Hyphenation adds break points inside words, governed by a family of
`Hyphenate…` attributes. The [composer](/docs/idml/typography/composer-and-opentype) chooses the
breaks within these limits.

## The `Justification` values

`Justification` is a paragraph attribute, on a `<ParagraphStyleRange>` or a paragraph style.

| Value | Lines | Last line |
| --- | --- | --- |
| `LeftAlign` | flush left, ragged right | same |
| `CenterAlign` | centred | same |
| `RightAlign` | flush right, ragged left | same |
| `LeftJustified` | justified to both edges | flush left |
| `CenterJustified` | justified to both edges | centred |
| `RightJustified` | justified to both edges | flush right |
| `FullyJustified` | justified to both edges | justified too, however short |
| `ToBindingSide` | flush toward the spine | same |
| `AwayFromBindingSide` | flush away from the spine | same |

`ToBindingSide` and `AwayFromBindingSide` follow the page: on a right-hand page the binding side
is the left, on a left-hand page the right. A paragraph's last line is the line before its
`<Br/>`, or the story's last line.

A line that holds a single word has no space to stretch. `SingleWordJustification` says how
such a line is set in justified text: `FullyJustified` (letter-spaced to fill the measure, the
value in almost every document of the census), `LeftAlign`, `CenterAlign` or `RightAlign`.

> **In Paged:** every value is set as the table describes, as measured against InDesign. The
> four justified values stretch the same lines and differ only in the last one, which is set
> flush left, centred, flush right or, for `FullyJustified`, justified as well. The two
> binding-relative values are resolved from the side of the spine the page sits on: on a
> right-hand page `ToBindingSide` is flush left, on a left-hand page flush right.
> `SingleWordJustification` is not read yet.

## The forced line break

A forced line break is the character U+2028 inside `<Content>`, typed in InDesign with
Shift+Return. It ends the line but not the paragraph: no first-line indent, space before or list
number follows it. In justified text the line before a forced break is justified to the full
measure, because it is not the paragraph's last line. See
[the paragraph model](/docs/idml/stories-text/the-paragraph-model).

> **In Paged:** U+2028 breaks the line inside the paragraph, and in justified text the line
> before it is justified.

## Word spacing, letter spacing and glyph scaling

Three triples on the paragraph set how far justified text may stretch or squeeze:

<AttrTable element="ParagraphStyle" attrs={['MinimumWordSpacing', 'DesiredWordSpacing', 'MaximumWordSpacing', 'MinimumLetterSpacing', 'DesiredLetterSpacing', 'MaximumLetterSpacing', 'MinimumGlyphScaling', 'DesiredGlyphScaling', 'MaximumGlyphScaling', 'SingleWordJustification']} />

Word spacing is a percentage of the font's normal space (InDesign's defaults: 80, 100, 133).
Letter spacing is a percentage added between characters (defaults 0, 0, 0). Glyph scaling is a
horizontal scale of the glyphs (defaults 100, 100, 100). The desired values also apply to ragged
text.

> **In Paged:** all three ranges feed the composer. <SupportBadge feature="typography.justification-spacing" />

## Hyphenation

<AttrTable element="ParagraphStyle" attrs={['Hyphenation', 'HyphenateWordsLongerThan', 'HyphenateAfterFirst', 'HyphenateBeforeLast', 'HyphenateLadderLimit', 'HyphenationZone', 'HyphenateCapitalizedWords', 'HyphenateLastWord', 'HyphenateAcrossColumns', 'HyphenWeight']} />

`Hyphenation` switches it on (it is on in InDesign's defaults). A word must have at least
`HyphenateWordsLongerThan` letters, and a break leaves at least `HyphenateAfterFirst` letters
before it and `HyphenateBeforeLast` after it. `HyphenateLadderLimit` caps how many consecutive
lines may end in a hyphen. `HyphenationZone` is a distance from the right edge within which ragged
text may end without hyphenating. `HyphenWeight` balances better spacing against fewer hyphens.
`AppliedLanguage` on the run picks the hyphenation dictionary.

> **In Paged:** hyphenation uses TeX hyphenation patterns per language, not the dictionaries
> InDesign uses, so a word can occasionally break one syllable differently. The attributes above
> are read; the hyphenation zone applies to ragged text only, as in InDesign.
> <SupportBadge feature="typography.hyphenation" /> <SupportBadge feature="typography.hyphenation-zone" />

## Kinsoku

Japanese and Chinese text forbids some characters at the start or end of a line, such as closing
brackets and small kana at the start. `KinsokuSet` names the rule table and `KinsokuType` how a
line is adjusted to obey it.

> **In Paged:** a built-in set of hard kinsoku rules is enforced when the paragraph sets
> `KinsokuType`; named tables are not honoured yet. <SupportBadge feature="typography.kinsoku" />

## Frequently asked questions

**What is the difference between `LeftJustified` and `FullyJustified`?**
Both justify every line to both edges. `LeftJustified` sets the last line flush left;
`FullyJustified` stretches the last line to the full measure too, however short it is.

**What do `CenterJustified` and `RightJustified` mean?**
Justified text whose last line is centred, or flush right, instead of flush left.

**How is a forced line break written, and how is the line before it set?**
As U+2028 inside `<Content>`. It ends the line without ending the paragraph, so in justified text
the line before it is justified like any other line that is not the last.

**What does `SingleWordJustification` do?**
It sets how a line holding a single word is placed in justified text: spread to fill the line, or
aligned left, centre or right.
