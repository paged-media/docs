**Hidden conditional text stays in the story but is left out of the page, and the visible text closes up around it.**

**In short:** Whether a run prints depends on the `Visible` flags of the conditions it
names in `AppliedConditions`. A run with no conditions always prints. A run with one
condition prints when that condition is visible. Hidden text is not composed at all: it
takes no space, and the lines are set as though it were not there. A run that names
several conditions, some visible and some hidden, is the open case: the rule InDesign
applies to it is being verified. Condition sets and indicators do not decide visibility
by themselves.

## One condition

For a run that names a single condition, the condition's `Visible` attribute is the whole
answer:

- `Visible="true"`: the run prints.
- `Visible="false"`: the run is left out.

The hidden run is not painted over or blanked. It is removed before the text is
composed, so it takes no width, the following text moves up to fill its place, and line
breaks are found as though its characters did not exist. The characters are still in the
story part; anything that reads the story's text gets them.

## Several conditions on one run

`AppliedConditions` can list several conditions. When all of them are visible the run
prints, and when all of them are hidden it does not. The case in between, a run under
one visible and one hidden condition, has two possible rules:

- the run is hidden when **any** of its conditions is hidden;
- the run is shown when **any** of its conditions is visible.

Which one InDesign applies is **under verification**. An earlier comparison against
InDesign's own PDF output suggested that it prints such runs, but that test file used a
condition spelling InDesign may not have read, so it does not settle the question. The
example below isolates the case: it has an unconditioned run, a run under the visible
condition only, a run under the hidden condition only, and the test run under both.

<ExampleEmbed example="conditional-two-conditions">
  Four runs: ALWAYS, PRINTONLY (visible condition), DRAFTONLY (hidden condition) and BOTH
  (one visible, one hidden). Whether BOTH prints decides the rule.
</ExampleEmbed>

Until it is settled, a file that has to print the same everywhere should avoid giving one
run both a visible and a hidden condition.

> **In Paged:** a run is hidden when any condition it names is hidden, so BOTH does not
> print in the example. This may change once InDesign's behaviour is confirmed. Hidden
> runs are removed before layout, so a story can report more runs than the page shows.

## Sets and indicators

A `ConditionSet` stores a combination of visibilities; it does not hide anything by
itself. Applying a set in InDesign changes the conditions' `Visible` flags, and those
flags, saved on each `Condition`, are what a reader sees. `ActiveConditionSet` in
`ConditionalTextPreference` only records which set was applied last.

A condition's indicator (`IndicatorMethod` and the `IndicatorColor` property) marks
conditional text on screen while editing and has no effect on which text prints.

> **In Paged:** visibility comes from each condition's own `Visible` flag; the active-set
> preference is not read. Scripts can change a condition's visibility, or activate a set,
> which shows its members and hides every other condition. Indicators are not drawn.

## Frequently asked questions

**Does hidden conditional text take up space?**
No. It is left out before the text is composed, so the visible text closes up around it.
The characters stay in the story part.

**What happens to a run with two conditions when one is hidden?**
That rule is still being verified against InDesign: either one hidden condition hides
the run, or one visible condition shows it. The `conditional-two-conditions` example
isolates the case.

**Does a condition set decide what is visible?**
Not directly. Applying a set changes each condition's `Visible` flag, and the flags are
what decide. `ActiveConditionSet` only records the set applied last.

**Do condition indicators print?**
They are an editing aid controlled by `ConditionalTextPreference`; with the
`ShowIndicators` value found in every census document, they appear on screen only.
