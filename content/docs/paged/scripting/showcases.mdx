**In short:** `paged.set(id, path, value)` accepts **<Fact id="script.settablePaths" /> settable paths**. The
lab below groups them into ten themes; each theme has a **script** that writes a few
of its paths on a starter document, so you can see them take effect. The full,
filterable list lives in [Settable paths](/docs/paged/scripting/settable-paths).

<Callout type="note">
Pick a theme, edit its script and press **Run**. The first Run loads the Paged editor
into the stage; after that, every theme you open runs at once. Each run starts from
the theme's starter document, mostly a page with one frame already selected, so the
script reads the selection (`JSON.parse(paged.selection())`) and addresses it as
`` `${kind}:${id}` ``. **Reset** puts the starter document back, and **Before** and
**After** switch between it and the result.
</Callout>
