**In short:** plugins add new *kinds of content* to a paged document. The
first-party plugins are built on the same [Plugin SDK](/docs/paged/plugin-sdk)
contract any third party uses, so they are its worked examples. Each renders into
the document through the engine's scene-layer surfaces and persists into the
`.paged` container. They are the built-in modules of the
[`paged-media/paged`](https://github.com/paged-media/paged/tree/main/modules) repository,
one directory each under `modules/` (`draw`, `web`, `image`, `sheet`, `data`, `doc`,
`slide`, `publish`). The engine is <Fact id="license.engine" />; the plugins are
<Fact id="license.plugins" />.

- **[paged.draw](/docs/paged/plugins/draw)** — vector drawing (pen, paths,
  pathfinder, SVG in and out).
- **[paged.web](/docs/paged/plugins/web)** — HTML and CSS as a content type.
- **[paged.image](/docs/paged/plugins/image)** — raster processing and PSD
  round-trip (Rust/WASM, GPU kernels).
- **[paged.sheet](/docs/paged/plugins/sheets)** — a spreadsheet engine with
  print-grade layout (Rust/WASM, XLSX round-trip).
- **[paged.data](/docs/paged/plugins/data)** — database publishing and automation
  (Rust/WASM, DuckDB).
- **[paged.doc](/docs/paged/plugins/doc)** — Word documents in and out.
- **[paged.slide](/docs/paged/plugins/slide)** — PowerPoint decks as native pages.
- **[paged.publish](/docs/paged/plugins/publish)** — IDML import and export, and
  PDF as an editable document.

Plus **[plugin-template](/docs/paged/plugins/template)** — the fork-and-go
starter, a repository of its own outside the monorepo.
