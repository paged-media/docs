**In short:** plugins add new *kinds of content* to a paged document. The five
first-party plugins are built on the same [Plugin SDK](/docs/paged/plugin-sdk)
contract any third party uses — they're the worked examples. Each renders into the
document through the engine's scene-layer surfaces and persists into the `.paged`
container.

- **[paged.draw](/docs/paged/plugins/draw)** — vector drawing (pen, paths,
  pathfinder, SVG I/O).
- **[paged.web](/docs/paged/plugins/web)** — HTML/CSS as a content type.
- **[paged.image](/docs/paged/plugins/image)** — raster processing + PSD
  round-trip (Rust/WASM, GPU kernels).
- **[paged.sheet](/docs/paged/plugins/sheets)** — a spreadsheet engine with
  print-grade layout (Rust/WASM, XLSX round-trip).
- **[paged.data](/docs/paged/plugins/data)** — database publishing + automation
  (Rust/WASM, DuckDB).

Plus **[plugin-template](/docs/paged/plugins/template)** — the fork-and-go
starter.
