**In short:** the engine is the heart of paged — a Rust workspace that reads an IDML
package and renders it pixel-faithfully. It lives at `engine/core` in the public
[`paged-media/paged`](https://github.com/paged-media/paged/tree/main/engine/core)
repository (it was the `core` repository until the monorepo replaced it), is
<Fact id="license.engine" />, and is the component every other one builds on, across
its wasm interface.

## What it does

- Parses full Adobe IDML — the design map, spreads, frames, stories with
  threading, cascade-resolved styles, gradients, and placed images.
- Lays out text with an InDesign-calibrated **Knuth–Plass** composer (hyphenation,
  tab stops, multi-font runs).
- Renders with one rendering model on two lanes: **Vello on WebGPU** in the browser,
  and **`vello_cpu`** on the CPU for the command line, headless fidelity testing and
  snapshots.
- Offers a mutation layer (insert/delete/edit, all undoable), a headless
  `ViewerSession`, PDF/X-4 export, and byte-faithful IDML round-trip.
- Keeps a document as a repository (`paged-repo`: content-addressed parts, commits,
  refs and evidence) and serves an MCP tool catalog (`paged-mcp`).

## How it's organized

A multi-crate workspace following the pipeline: `idml-import` → `paged-scene` →
`paged-text` → `paged-compose` → `paged-gpu`, with `idml-export` writing IDML back,
`paged-model` holding the document model, `paged-renderer` orchestrating
and `paged-fidelity` running the ΔE2000/SSIM diff harness. The scripting surface
lives in `paged-script` (Boa) + `paged-run` (headless NDJSON session), the `paged`
command line in `paged-cli`, and the public scripting catalog in `paged-introspect`.

## How you consume it

Inside the monorepo, the editor and the modules build against the engine's wasm
packages at the same revision. Outside it, the engine ships on npm, versioned
`0.<protocol>.<patch>`: the release these docs pin, <Fact id="engine.version" />, was
published under <Fact id="license.engine.release" /> as `@paged-media/canvas-wasm`,
`introspect-wasm`, `sdk` and `idml-viewer`. On the main line the public packages are
`@paged-media/paged` (the engine with the `paged` command, from `packages/paged`) and
`@paged-media/viewer`. The [renderer reference](/docs/paged/engine/the-renderer) documents its behavior;
the [scripting layer](/docs/paged/scripting) documents its `paged.*` surface.
