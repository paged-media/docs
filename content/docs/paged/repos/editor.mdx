**In short:** the editor is the app — full document editing on top of the
[engine](/docs/paged/repos/core). It lives at `apps/editor` in the public
[`paged-media/paged`](https://github.com/paged-media/paged/tree/main/apps/editor)
repository (it was the `editor` repository until the monorepo replaced it) and is
<Fact id="license.editor" />. A React shell talks to the engine wasm
running in a Web Worker that renders to an `OffscreenCanvas`, with a
`SharedArrayBuffer` carrying camera and gesture state for real-time interaction.

## What it does

- Full editing: insert/delete frames, edit text, apply paragraph/character/object
  styles, transform with gestures (translate, rotate, scale, shear).
- A panel system (properties, styles, swatches, layers, pathfinder, …), a command
  palette, and a [`paged.*` script editor + REPL](/docs/paged/scripting).
- Hosts the content [plugins](/docs/paged/plugins) — draw, image, sheets, web,
  data — through the [Plugin SDK](/docs/paged/plugin-sdk).

## How it's organized

Packages of the monorepo's Bun workspace: `apps/canvas` (the app), `packages/client` (the wasm boundary —
the `CanvasClient`, the wire protocol + `PROTOCOL_VERSION`, the SAB primitives),
`packages/shell` (state, registries, dockview substrate, theme), `packages/catalog`
(declarative commands/panels), `packages/repository` (documents as local
repositories), `packages/tools`, and `packages/ui` (input primitives).

## How it consumes the engine

It builds against the engine's wasm packages from the same monorepo revision, so
the editor and the engine it runs always share one wire protocol version. The
render architecture and fidelity suite are covered under
[testing](/docs/paged/testing).
