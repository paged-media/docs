**In short:** the viewer is the open, **read-only** counterpart to the editor — a
WebGPU IDML viewer with renderer-core only (no mutation, canvas-editing, or
scripting). It's the standalone community viewer **and** the live preview embedded
in this documentation.

## What it is

The viewer ships from the [engine](/docs/paged/repos/core)'s
`engine/core/web/idml-viewer` in the
[`paged-media/paged`](https://github.com/paged-media/paged/tree/main/engine/core/web/idml-viewer)
repository and is published as **`@paged-media/viewer`**, with the low-level
WebGPU session as `@paged-media/viewer/session` (releases before v0.74 were named
`@paged-media/idml-viewer` and `@paged-media/sdk`). This site's `<live preview>` consumes the published
package directly — the same renderer the
editor uses, minus everything to do with editing.

## Status

The separate `viewer` repository was never more than a placeholder and is archived;
the viewer ships from the engine's directory. A standalone app would be a thin shell
over the npm package.
