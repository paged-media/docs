**In short:** paged is a multi-repo system. The engine is public; the commercial
app and its plumbing are private. Each repo below has a page with what it does,
how it's built, and its recent activity.

- **[core](/docs/paged/repos/core)** — the Rust render engine (public).
- **[editor](/docs/paged/repos/editor)** — the commercial editing frontend.
- **[editor-server](/docs/paged/repos/editor-server)** — the REST backend.
- **[viewer](/docs/paged/repos/viewer)** — the slim read-only WebGPU viewer.
- **[state](/docs/paged/repos/state)** — the capability registry + dashboard.
- **[docs](/docs/paged/repos/docs)** — this site.
- **[brand](/docs/paged/repos/brand)** — the design tokens / cockpit kit.

The five content plugins have their own section: **[Plugins](/docs/paged/plugins)**.
