**In short:** the product is one public repository,
[`paged-media/paged`](https://github.com/paged-media/paged), that holds the engine,
the editor, the server, the viewer, the built-in modules and the extension SDK at one
revision. Everything in it is <Fact id="license.engine" />. Three repositories sit
beside it: the capability registry, this documentation site, and the brand kit.

## The monorepo

Each component keeps its own directory with its own README, docs and build
instructions. The per-component repositories it was assembled from (`core`,
`editor`, `editor-server`, `viewer`, `plugin-sdk` and the `plugin-*` repositories)
are archived and read-only; their history is part of the monorepo.

| Component | Path in `paged-media/paged` | Page |
| --- | --- | --- |
| The render engine | `engine/core` | [core](/docs/paged/repos/core) |
| The viewer | `engine/core/web/idml-viewer` | [viewer](/docs/paged/repos/viewer) |
| The editor | `apps/editor` | [editor](/docs/paged/repos/editor) |
| The server (paged.server) | `apps/server` | [server](/docs/paged/repos/editor-server) |
| The `paged` npm package (engine and `paged` command) | `packages/paged` | [command line](/docs/paged/cli) |
| The extension contract and SDK | `platform/extensions` | [Plugin SDK](/docs/paged/plugin-sdk) |
| The built-in modules | `modules/{publish,draw,web,image,sheet,data,doc,slide}` | [Plugins](/docs/paged/plugins) |

## Beside the monorepo

- **[cockpit](/docs/paged/repos/cockpit)** — the capability registry and its test-evidence join.
- **[docs](/docs/paged/repos/docs)** — this site.
- **[brand](/docs/paged/repos/brand)** — the design tokens / cockpit kit.
- **[plugin-template](/docs/paged/plugins/template)** — the starter for a plugin of
  your own, built only on the published packages.
