**The engine is the open Rust code that reads an IDML package and turns it into
pages.** These chapters describe Paged's implementation. The format itself is
described in the [IDML Reference](/docs/idml/overview).

- **[How Paged reads IDML](/docs/paged/engine/how-paged-reads-idml)** — from an
  `.idml` or `.paged` file to pages: the adapter, the model, the build.
- **[The renderer](/docs/paged/engine/the-renderer)** — the pipeline from parsed
  package to display list to pixels, and the rendering backends.
- **[Parser internals](/docs/paged/engine/parser-internals)** — how the reader
  walks the package, recovers from damaged input, and stays within memory.
- **[Test corpus](/docs/paged/engine/test-corpus)** — how the engine is tested,
  and how every example in the IDML Reference is validated against it.
