**In short:** this page lists the server's REST endpoints, **generated from its
OpenAPI spec**, so the reference matches the running service. The editor-server
it documented exposed the editor's account, storage, billing and asset features.

<Callout type="warn">
The editor-server is retired. Its replacement, [paged.server](/docs/paged/repos/editor-server) (`apps/server` in the
[paged-media/paged](https://github.com/paged-media/paged/tree/main/apps/server)
repository), syncs repositories and serves an MCP endpoint, and publishes no OpenAPI
specification yet, so the endpoint list below is empty until it does.
</Callout>
