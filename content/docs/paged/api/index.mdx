**In short:** paged exposes four programmable surfaces. Each reference below is
**generated from its own source of truth** — the engine's scripting catalog, the
SDK package surface, the server's OpenAPI spec, and the plugin manifest schema —
so none of them drift from the running code.

<ApiReferenceIndex />

## Which one do I want?

- **[Scripting (`paged.*`)](/docs/paged/scripting)** — read and author the open
  document from inside the editor's script panel, the REPL, or headless via
  `paged-run`. Start with the [examples](/docs/paged/scripting/examples).
- **[Viewer SDK](/docs/paged/sdk)** — embed a WebGPU IDML viewer on a canvas:
  load a document, drive the camera, render to bytes, listen for events.
- **[REST API](/docs/paged/api/rest)** — the editor-server HTTP surface for
  accounts, document storage, billing, and assets.
- **[Plugin manifest](/docs/paged/plugin-sdk)** — the declarative contract a
  plugin bundle ships to contribute tools, panels, commands, and document
  behaviour.
