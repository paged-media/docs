**In short:** you're reading it. `docs` is a public Fumadocs (Next.js App Router +
MDX) site with two pillars: the **[IDML Reference](/docs)** (the format) and **The
Paged Platform** (the system). It deploys as a static export to GitHub Pages at
docs.paged.media.

## How it stays current

The platform pages and the IDML support badges are **generated from the system's
own sources** at build time — the [registry](/docs/platform/repos/state), the
engine [scripting catalog](/docs/platform/scripting), the
[plugin manifest schema](/docs/platform/plugin-sdk), the server
[OpenAPI spec](/docs/platform/api), and the repos' commit history. A pin file
records the sources; a nightly rebuild and on-push triggers keep it fresh; and a
freshness gate flags authored prose whose source has moved. The design rule:
*a page is either generated or guarded — never just hoped-to-be-current.*

## How it consumes the engine

The IDML examples are validated in CI against the real renderer (`paged-inspect`
built from a pinned core release), and the live preview embeds the published
[viewer](/docs/platform/repos/viewer). The clean-room rule governs the IDML
reference prose.
