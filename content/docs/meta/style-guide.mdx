The full style guide lives in the repo; these five rules are its spine, and a
reviewer can hold any page to them.

1. **Short sentences.** If a sentence has two ideas, it is two sentences.
2. **One concept per page.** If a page wants to be two things, it is two pages.
3. **Examples before explanation.** Show the thing, then explain it.
4. **No marketing voice.** This is a technical reference, not a pitch. No calls to
   action inside chapter content.
5. **Declare the tier and Diátaxis mode, and honor them.** Every page is exactly
   one reader tier (🟢/🟡/🔴) and one mode (tutorial / how-to / reference /
   explanation), set in frontmatter and shown as the difficulty label. The label is
   derived from the frontmatter, so the two can never disagree.

## Visual identity

A neutral, restrained technical reference — not a product surface. Reserved
palette, monospace for XML, generous whitespace. Diagrams earn their place; every
major concept gets one.

## One line we always keep straight

Paged is a native renderer for paged media, starting with IDML — a separate
project from the CSS-based Paged.js polyfill. We credit Paged.js and the CSS Paged
Media work where relevant and never imply a fork or affiliation.
