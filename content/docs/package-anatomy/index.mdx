An IDML document is a ZIP archive of XML parts. This section walks the archive
from the outside in: the container itself, the manifest that names everything (the
*design map*), the shared resource parts, the content parts that hold pages and
text, and finally the references that wire them together.

If you have not yet opened one, start with
**[read one by hand](/docs/foundations/read-one-by-hand)** — this section explains
what you saw there.
